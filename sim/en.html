TASK ORDER

  1. Takeoff
  2. Ring → window gate → triangle gate → window gate
  3. 6-pole slalom
  4. Drops: Ivan → MIT (one drop per task; a miss adds +10 s and moves on)
  5. Orbit the tank once → tank drop (top attack)
  6. Fast return (boost) → tunnel
  7. Bunker: go around the side, enter the front window → scan 1.5 s → exit through a window (the left one or the one you came in)
  8. FINISH gate → land on the right H-pad

STICK ASSIGNMENT

THROTTLE STICK TYPE

With a non-centering throttle, center = 'altitude hold', push up to climb, pull down to descend (Training/Easy). A wide band around center is ignored.

CALIBRATION

TUTORIAL

Explanation and practice for each obstacle · start from any lesson (completed lessons show ✓)

Each lesson circles the obstacle while explaining it, then starts you right in front of it. No timer or penalties, and payloads refill. Difficulty follows the menu setting ( 'Training' is recommended at first).

DEM → TERRAIN

Reprojects a digital elevation model into the course frame and applies it as terrain

Click the map to put the course centre there. Yellow square = high-res area (1.2 km), orange = flight course, arrow = downrange direction.
