# FPV Terrain Trainer (시제품 v0.5)

실제 지형(DEM·수치지형도) 위에 드론 장애물 코스를 깔아 연습하는 웹 시뮬레이터입니다.
GitHub Pages 주소: `https://uyonyi.github.io/range/sim/` (영문: `en.html`)

## 구조

| 경로 | 내용 |
|---|---|
| `index.html`, `en.html` | 한국어 / 영어 화면 |
| `js/app.ko.js`, `js/app.en.js` | 시뮬레이터 본체 (빌드 결과) |
| `lib/` | three.js r149, geotiff.js, proj4 |
| `sites/<현장>.js` | 현장 데이터: 지형 격자(코스 주변 5 m + 원경 60 m), 코스, 지형지물 |
| `src/` | 소스와 빌드 스크립트 (`python3 build.py public ..`) |
| `tools/` | GIS 처리 스크립트 |

## 현장: 영인산 (아산)

- 지형: 수치지형도 1:5,000 아산068 등고선·표고점 → TIN 보간 → 5 m DEM (EPSG:5186), 도엽 밖은 DEM 90 m (EPSG:5179) 와 150 m 폭으로 섞음
- 코스: 사용자 지정 경로(위경도 5점, 약 560 m)를 따라 드론 장애물만 배치
- 정사영상: 국토지리정보원 정사영상 2025 아산068·058 (0.25 m, EPSG:5186)을 코스 구간(약 457×795 m)으로 잘라 `sites/yeongin_ortho.tif`(JPEG 압축)로 두고, 시작할 때 자동으로 바닥에 입힘 (가장자리 15 m 는 기본 바닥과 섞음)
- 나무: 정사영상에서 수관(햇빛 받는 나무 꼭대기)을 검출해 위치·크기·색을 뽑고(약 5,200그루), 정사영상 밖은 도로·경지를 피해 절차적으로 심음(`tools/mktrees.py`). 비행 경로·장애물 둘레는 비우고 가장자리에 덤불. 거리별 3단계 세밀도, 충돌 판정 있음
- 기체 7종 (공개 제원 수준 근사): Skydio X2D(50 km/h) · Parrot ANAFI USA(53 km/h) · FPV 레이싱(140 km/h, 수동 Acro 선택) · RQ-11B Raven(31~81 km/h, 60~90분, 손 투척) · RQ-20B Puma(37~83 km/h, 3.5시간) · 자폭 FPV(108 km/h) · 자폭 고정익(순항 94 / 급강하 158 km/h)
- 부스트: 켜기/끄기 (어디서나, 기체 최고 속도까지)
- 임무: 장애물 코스 · 숲길 통과(나무 사이 좁은 길, 쓰러진·기운 나무, 좁은 틈) · 타임 레이스(계곡 링) · 정찰(수치지형도의 실제 건물) · 타격(표적 차량 돌입, 명중 오차) · 산불 감시(열화상으로 불씨 찾아 EPSG:5186 좌표 보고) · 자유 비행
- 추가 시나리오: 수색·구조(숲 속 실종자 열화상 수색 → 구조 키트 투하 → 착륙 복귀) · 차량 추적(수치지형도 실제 도로를 달리는 차량 60초 시야 유지) · 능선 종주(DEM 최소비용 경로 분석으로 뽑은 능선 따라 정상 왕복)
- 밤 시간대(달빛·드론 조명·LED 게이트), 열화상 보기(T 키, 백색=고온), 바람(없음·약 3·강 7 m/s, 높이·능선 노출·돌풍 반영)
- 지형지물: 도로·소로·하천·경지는 바닥에 그림, 건물은 최소 외접 사각형으로 세움 (높이는 면적으로 추정)

## 처리 순서 (tools/)

1. `mkdem.py` — DXF 등고선(F0017111·F0017114)·표고점(F0027217) → 5 m 격자
2. `mkcomp.py` — 5 m 도엽 DEM + 주변 90 m DEM 합성 GeoTIFF
3. `mkcourse.py` — 경로 좌표를 따라 장애물 재배치 (묶음 안 간격 유지, 사이만 늘림)
4. `src/mkpkg.js` — 브라우저 처리기(재투영·리샘플)로 지형 패키지 생성
5. `mkvec.py` — 도로·하천·경지·건물을 코스 좌표로 변환
5-1. `mktrees.py` — 정사영상 수관 검출 → 나무 목록
6. `src/build.py public <출력 폴더>` — 공개판 빌드

원본 수치지형도·DEM 파일은 저장소에 넣지 않습니다.
